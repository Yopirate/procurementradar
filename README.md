# Procurement Radar Maroc — AWB

Application de veille achats et intelligence marché pour AWB.

## Déploiement GitHub Pages

1. Uploadez `index.html` dans ce repository
2. Allez dans **Settings** → **Pages**
3. Source : **Deploy from a branch** → `main` → `/ (root)`
4. Cliquez **Save**
5. Votre app sera accessible sur `https://[votre-username].github.io/[nom-repo]/`

## Configuration clé API

À la première ouverture, entrez votre clé API Claude (`sk-ant-...`) dans la bannière qui apparaît.
La clé est stockée localement dans votre navigateur.

## Fonctionnalités

- 1 260 fournisseurs marocains
- Veille marchés & alertes en temps réel
- Actualité entreprises Maroc (juillet 2026)
- Top 100 CA S1 2026
- Analyse IA avec upload de documents
- Mises à jour automatiques via Claude API
